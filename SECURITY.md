# Security policy

## Supported code

The current `main` branch is the only branch considered for security fixes while the project is a prototype.

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue.

Send a private report to `contact@lepotager.org` with the subject `Security — Delivery Aggregator`. Include the affected commit, reproduction steps, expected impact and any suggested mitigation.

Never attach real platform credentials, customer data, session cookies or production exports. Use synthetic test data.

The project must not rely on scraping authenticated user accounts or storing third-party account credentials.
