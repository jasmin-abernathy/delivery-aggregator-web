# Contributing

Contributions are welcome for the comparison prototype, data adapters, accessibility, documentation and tests.

Please keep contributions compatible with these project rules:

- no scraping of authenticated user accounts;
- no storage of third-party account passwords, cookies or access tokens;
- no fabricated prices, availability or partnerships;
- clearly distinguish mock/demo data from verified integrations;
- keep data collection minimal and documented;
- run available tests before proposing a change.

Report security issues privately using `SECURITY.md`.

Contributions are provided under AGPL-3.0-only.
